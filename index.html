DNCPublisher

Content publishing automation for creators

About this application

DNC Publisher is a personal content publishing tool built for the creator @dois_no_corre. It automates the process of uploading short-form video content to the creator's own account.


The application:

  • Authenticates the creator's account via OAuth 2.0
  • Uploads pre-edited video files directly to the creator's account
  • Publishes or schedules videos as drafts for manual review
  • Does not collect, store, or share any user data with third parties

This is a private, single-user tool — not a public application or service.

This site also serves as the OAuth callback endpoint for the application's authorization flow.
